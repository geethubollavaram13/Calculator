# Advanced Scientific Calculator

A modern and responsive Scientific Calculator built using HTML, CSS, and JavaScript. This calculator performs basic arithmetic operations as well as scientific calculations with an attractive user interface.

## Features

✅ Addition, Subtraction, Multiplication, Division

✅ Percentage Calculation

✅ Square Root Function

✅ Square Function (x²)

✅ Trigonometric Functions
- Sin
- Cos
- Tan

✅ Logarithmic Function

✅ Clear (AC) Button

✅ Delete (DEL) Button

✅ Keyboard Support

✅ Responsive Design

✅ Modern Glassmorphism UI

✅ Smooth Hover Animations
